## 2. Scope
All employees, contractors, systems, applications, and data owned or managed by the organization.

## 3. Policy Statements
### 3.1 Principles
- Least privilege
- Need-to-know
- Separation of duties
- Default deny

### 3.2 Account Management
- Unique IDs per user; no shared accounts
- Joiner / Mover / Leaver process
- Service and generic account ownership
- Dormant account review and disablement (e.g., 90 days)

### 3.3 Authentication
- MFA requirements (all remote, privileged, and cloud access)
- Password / passphrase requirements (reference Password Policy)
- Session timeout and lockout thresholds

### 3.4 Authorization
- Role-based access control (RBAC) model
- Access request and approval workflow
- Data owner approval for sensitive systems

### 3.5 Privileged Access
- Separate admin accounts
- Just-in-time / time-bound elevation
- Session recording and PAM tooling
- Break-glass procedure

### 3.6 Remote & Third-Party Access
- VPN / zero-trust access requirements
- Vendor access approval, time limits, monitoring

### 3.7 Physical Access
- Badge control, visitor logging, secure areas

### 3.8 Access Reviews
- User access review: quarterly (privileged), semi-annual (standard)
- Review evidence retention

### 3.9 Logging & Monitoring
- Authentication and privileged activity logged and reviewed
