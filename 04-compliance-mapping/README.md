# Compliance Mapping

Mappings from this repository's documents to common security and privacy frameworks, plus a gap analysis showing what to write next.

> Draft guidance only. Mappings show what the **draft documents** address; they do not prove controls are implemented. Validate with your auditor, assessor, or counsel.

## How to Use
1. Pick the frameworks you are subject to or targeting.
2. Open the framework file and review **Gap** and **Partial** rows.
3. Use [gap-analysis.md](gap-analysis.md) to choose which documents to create next.
4. Collect implementation evidence for rows marked **Covered**.
5. Update mappings whenever you add or change a document.

## Conventions
- Coverage values: **Covered**, **Partial**, **Gap**
- Control numbering follows the version stated in each file header
- Check standards bodies and regulators for new versions before audits; frameworks change
